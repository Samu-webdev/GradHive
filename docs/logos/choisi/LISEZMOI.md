# Logo web et icône mobile GradHive

Le logo web horizontal, le favicon et l’icône mobile partagent le même monogramme **GH**, en grand blanc sur une tuile bleue arrondie à effet de verre subtil. La tuile n’a pas de contour ; le signe reste lisible aux petites tailles.

| Fichier | Usage |
|---|---|
| `logo-gradhive-web.png` / `.svg` | Logo horizontal (symbole + « GradHive ») : site web, mémoire, présentation |
| `icone-gradhive-mobile.png` / `.svg` | Icône carrée GH (1024 × 1024) : source à utiliser pour les déclinaisons mobiles |

Le favicon et le manifeste web installable partagent le monogramme GH de `web/public/favicon.svg`. Le SVG est la source vectorielle de référence ; les ressources raster mobile sont exportées à partir de cette géométrie. Le logo horizontal correspondant est `logo-gradhive-web.svg`. Les autres propositions (B et C) sont conservées dans le dossier parent comme archives et ne sont plus utilisées par l’application.
